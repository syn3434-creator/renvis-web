お問い合わせフォームについて
GitHub Pagesは静的サイトのため、フォーム内容をサーバーへ自動送信しません。
入力確認後、info@renvis.co.jp宛てのメール作成画面を開く仕様です。

上書き方法
1. ZIPを「すべて展開」
2. renvis-webフォルダの中身をすべてコピー
3. 現在使用中のrenvis-webへ貼り付け
4. 同名ファイルは「置き換える」
5. GitHub Desktopで「Ver1.6 公開前修正」と入力
6. Commit to main
7. Push origin
